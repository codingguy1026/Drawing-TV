# Drawing TV

영상, 짧은 클립, 커뮤니티를 잇는 독립형 창작 SNS. **피드는 2026년, 채널은 1996년.**

## 실행

```bash
npm install
npm run dev
```

- `/` : Signal 소셜 피드 (발견/팔로잉/저장, 좋아요, 댓글, 텍스트 글쓰기)
- `/videos` : 기존 영상 홈 및 추천 콘텐츠
- `/shorts` : 짧은 영상 섹션
- `/watch/[id]` : 동영상 시청 화면
- `/upload` : 업로드 UI
- `/subscriptions` : 구독 UI
- `/explore` : 탐색

### SNS 1단계 시제품 안내

현재 홈 피드는 **브라우저 `localStorage` 기반 체험판**입니다. 글 작성, 팔로우, 좋아요, 댓글, 저장 상태는 해당 브라우저에서만 유지되며 **서버 게시나 다른 사용자와의 공유는 일어나지 않습니다**. 콘텐츠 카드 및 사용자 계정은 데모 데이터입니다. 업로드, 인증, 피드의 서버 DB 저장, 권한 검증, 댓글 신고/차단/모더레이션, 크리에이터 프로필은 다음 개발 단계에서 구현해야 합니다.

Next.js 16 App Router + React 19 + Tailwind CSS 4.
