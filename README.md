# Drawing TV

DTV is a video platform where anyone can discover videos, upload content, grow a channel, and go live.

> Your channel. Your broadcast.

## Stack

- Next.js
- React
- TypeScript
- Plain CSS (first prototype)

## Development

```bash
npm install
npm run dev
```

The first prototype focuses on the home feed, navigation, categories, D-Clips, and ON AIR visual language.
