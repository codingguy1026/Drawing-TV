# Drawing TV

DTV is a video platform where anyone can discover videos, upload content, grow a channel, and go live.

> Your channel. Your broadcast.

## Stack

- Next.js 16.3.4
- React 19
- TypeScript
- Plain CSS for the first prototype

## Prototype v0.1

The first working DTV home experience includes:

- Responsive desktop and mobile layout
- Collapsible navigation sidebar
- Search filtering
- Category filtering
- LIVE / ON AIR view
- Recommended video grid
- D-Clips vertical video rail
- Prototype interaction toasts
- GitHub Actions build check

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` and start broadcasting the pixels. 📺
